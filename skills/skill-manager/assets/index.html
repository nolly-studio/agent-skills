Skill manager

Your personal skills in ~/.claude/skills. Each change is saved to skillOverrides in ~/.claude/settings.json right away. New sessions pick it up.

-skills
-fully on
-off
-chars of descriptions per session
On: listed with its description, so Claude can pick it on its own or you can run /name.
Name only: listed by name without the description. Cheaper, but Claude picks it less reliably.
Slash only: hidden from Claude. Runs only when you type /name.
Off: not loaded at all.
